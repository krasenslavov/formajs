# Contributing

Branches: `main` holds stable releases only; all work happens on `dev` and is merged into `main` for each release. Open pull requests against `dev`.

1. Fork and clone the repository, then `npm install`.
2. Edit `src/js/forma.js` or `src/scss/`. Add or update tests in `test/`.
3. Run `npm run build && npm test`. Commit the updated `dist/` and docs copies.
4. Open a pull request describing the change.
